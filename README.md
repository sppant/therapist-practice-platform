# Therapist Practice Platform

A practice management and online booking platform for independent therapists and therapy practices: availability, appointments, clients, and a public booking page. Scheduling only. No payments, clinical records or therapy notes.

> **Status: planning.** No application code yet. This README is expanded as the product is built (features, screenshots, setup, demo credentials, known limitations).

## Planned stack
Java 21 · Spring Boot · PostgreSQL · Flyway · Nuxt 3 · Vue 3 · TypeScript · Tailwind CSS · Docker Compose · GitHub Actions

## Repository
- `docs/`: requirements, design, architecture, decisions and progress (`docs/project-progress.md`)
